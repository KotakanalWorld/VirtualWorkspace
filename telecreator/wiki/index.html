🚀 Getting StartedНачало работы

Create your first Telegram bot in minutes — no coding required.

Создайте первого бота за минуты — без программирования.

Go to @BotFather in Telegram → send /newbot → choose name and username → copy the token
Зайди в @BotFather → отправь /newbot → выбери имя → скопируй токен
Open Telebot Creator → sign up with email → click + Add Bot → paste the token
Открой Telebot Creator → зарегистрируйся → нажми + Add Bot → вставь токен
Click Open editor → create a new flow → add a Trigger + action blocks
Нажми Open editor → создай поток → добавь триггер и блоки действий
Click ▶ Run Bot → test your bot in Telegram → check logs in the console panel
Нажми ▶ Run Bot → протестируй в Telegram → смотри логи в консоли
💡 Tip:💡 Совет: Each bot can have multiple flows. Each flow = one scenario (e.g. /start command, button press, text message). У каждого бота может быть несколько потоков. Каждый поток = один сценарий (например /start, нажатие кнопки, текстовое сообщение).

⚡ TriggersТриггеры

Triggers define when a flow starts. Each flow must have exactly one trigger as the first block.

Триггеры определяют когда запускается поток. Каждый поток должен начинаться с одного триггера.

⌨️
cmd
Slash command trigger. E.g. /start, /help, /buy
Триггер команды. Например /start, /help, /buy
💬
on_text
Fires when message contains/equals/starts with text. Supports multiple OR conditions.
Срабатывает когда сообщение содержит/равно тексту. Поддерживает несколько условий OR.
🔘
on_cb
Fires when user presses an inline button (callback query).
Срабатывает при нажатии inline кнопки.
🖼
on_photo
Fires when user sends a photo.
Срабатывает при отправке фото.
📄
on_doc
Fires when user sends a document/file.
Срабатывает при отправке файла.
👋
on_join
Fires when a user joins the group.
Срабатывает когда пользователь входит в группу.
🚪
on_leave
Fires when a user leaves the group.
Срабатывает когда пользователь покидает группу.
💰
on_payment
Fires after successful Stars or TON payment.
Срабатывает после успешной оплаты Stars или TON.
📊
on_var
Fires when a variable equals a specific value.
Срабатывает когда переменная равна значению.
🚨
on_flood
Anti-spam trigger. Fires when user sends too many messages.
Антиспам триггер. Срабатывает при флуде.

📦 BlocksБлоки

Action blocks define what the bot does. Add them after the trigger in any order.

Блоки действий определяют что делает бот. Добавляй их после триггера в любом порядке.

Random

Случайное число или выбор из списка. Результат в переменную.

💳 PaymentsОплата

Accept Telegram Stars and TON cryptocurrency payments directly in your bot. Payment blocks require server mode for reliable processing.

Принимай оплату Stars и TON прямо в боте. Блоки оплаты требуют сервер для надёжной работы.

⚠ Important:⚠ Важно: Payment blocks require Server mode (☁️ Server). The browser can't handle pre_checkout_query fast enough (must respond in 10 seconds). Блоки оплаты требуют режим сервера (☁️ Server). Браузер не успевает ответить на pre_checkout_query за 10 секунд.
⭐
Stars Payment
Send a Telegram Stars invoice. Set title, description, amount in Stars, and payload. Works in private chats.
Отправить инвойс Telegram Stars. Укажи название, описание, сумму в Stars и payload.
💎
TON Payment
Accept TON cryptocurrency via @CryptoBot. Requires CryptoBot API key.
Принять TON через @CryptoBot. Нужен API ключ от @CryptoBot.
✅
Check Payment
Verify payment was successful. Use after on_payment trigger. Saves "ok"/"fail" to variable.
Проверить успешность оплаты. Сохраняет "ok"/"fail" в переменную.
🧾
Send Receipt
Generate unique one-time code (e.g. TC-A3F2-X9K1). User enters it on site to activate Premium.
Сгенерировать уникальный код (напр. TC-A3F2-X9K1). Юзер вводит на сайте для активации Premium.
Admin only

Payment Flow Example

Пример потока оплаты

Flow 1 — /buy command:
  Trigger: cmd /buy
  → Inline keyboard with "⭐ Buy for 100 Stars" button (callback: buy_stars)

Flow 2 — Stars invoice:
  Trigger: on_cb → buy_stars
  → Stars Payment (amount: 100, payload: premium_30)

Flow 3 — After payment:
  Trigger: on_payment (payload: premium_30)
  → Send Receipt (save to: receipt_code)
  → Send Text: "Your code: {{receipt_code}} — enter it on the site!"

Хранить и получать данные между потоками. Три типа с разной областью видимости.

TypeТип ScopeОбласть Use caseКогда использовать
🟡 Local Per user, per chatКаждый юзер, каждый чат User score, personal settings, quiz answersОчки юзера, личные настройки, ответы в квизе

📜 Custom Script

Execute any JavaScript code inside your bot flow. Access Telegram API, make HTTP requests, call external APIs — anything is possible.

Выполняй любой JavaScript в потоке бота. Telegram API, HTTP запросы, внешние API — всё возможно.

Available Variables

Доступные переменные

bot          — Telegram Bot API proxy
chatId       — Current chat ID
msg          — Full message object (msg.text, msg.from.id, etc.)
sub(text)    — Replace {{variables}} in text
setVar(key, value, type)  — Set variable ('local'/'group'/'global')
getVar(key, type)         — Get variable value
sleep(ms)    — Pause for milliseconds
fetch(url, options)       — HTTP request (GET/POST/etc)
log(text)    — Add message to bot console

Example — ChatGPT via OpenRouter

Пример — ChatGPT через OpenRouter

const apiKey = 'sk-or-...';
const res = await fetch('https://openrouter.ai/api/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer ' + apiKey
  },
  body: JSON.stringify({
    model: 'meta-llama/llama-3.3-70b-instruct:free',
    messages: [
      { role: 'system', content: 'You are a helpful assistant.' },
      { role: 'user', content: msg.text }
    ]
  })
});
const data = await res.json();
const reply = data.choices[0].message.content;
await bot.sendMessage(chatId, reply);

В редакторе: нажми ☁️ Server → Вкладка 1 → скачай server.js и package.json
Upload both files to a GitHub repository
Загрузи оба файла в GitHub репозиторий
render.com → New → Web Service → connect GitHub → Build: npm install → Start: node server.js
Add environment variable: SERVER_KEY=your-secret
Добавь переменную: SERVER_KEY=твой-секрет
In editor: ☁️ Server → Tab 3 → enter URL + key → Connect
В редакторе: ☁️ Server → Вкладка 3 → URL + ключ → Connect
